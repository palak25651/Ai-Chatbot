# AI Chatbot 🤖

A simple AI Chatbot web application built using HTML, CSS, and JavaScript. This project provides an interactive chatbot interface where users can communicate with the bot through a clean and responsive UI.

## Features

* Interactive chatbot interface
* Responsive design for different screen sizes
* User-friendly chat experience
* Built with vanilla JavaScript
* Simple frontend implementation
* Lightweight and easy to run

## Tech Stack

* HTML5
* CSS3
* JavaScript

## Project Structure

```text
├── index2.html       # Main webpage structure
├── styles2.css       # Styling and UI design
├── script2.js        # Chatbot functionality
├── README.md         # Project documentation
├── chatbot (1).pptx  # Project presentation
```

## Installation & Setup

1. Clone the repository:

```bash
git clone https://github.com/palak25651/Ai-Chatbot.git
```

2. Open the project folder:

```bash
cd Ai-Chatbot
```

3. Open `index2.html` in your browser.

## Usage

* Open the application in your browser
* Type your message in the chat input
* Interact with the chatbot interface
